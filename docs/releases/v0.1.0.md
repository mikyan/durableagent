# DurableAgent v0.1.0

首个可安装的预发布版本。Android 16（API 36）起，产品支持 ARM64；同一 APK 同时包含 x86_64，用于开发模拟器验证。

提供持久会话、模型连接与凭据、草稿及附件、项目与工作区、通过官方 Termux 进行本地命令和原文件操作、执行核验与停止、条件恢复后的自动续跑、省流策略及 Console 界面。

## 安装和使用

下载 `durableagent-v0.1.0.apk`；`SHA256SUMS.txt` 和 `release-metadata.json` 提供文件摘要、源码提交及签名证书摘要。应用使用独立的 Release 签名，并关闭调试入口。

需要自行安装官方 Termux。打开本应用的“工具 → 本地执行”，复制完整初始化命令，在 Termux 执行后返回连接；模型连接和 API Key 在应用内配置。升级或初始化不会授权清空、替换现有 Termux 数据。

已有开发版 `dev.durableagent.probe` 使用另一张调试证书，不能直接被本发布包覆盖安装。不要为安装首包而贸然卸载开发版：本应用私有数据不参与系统备份，卸载会丢失其本地记录；可先使用另一台设备或独立模拟器。后续正式包沿用本次 Release 签名。

## 验证范围与已知问题

此预发布不表示首版全部设备验收通过。T01—T16 已按各自记录的范围完成开发验证；T17 仍有未决问题和设备缺项，详见 [验收报告](https://github.com/mikyan/durableagent/blob/v0.1.0/docs/evidence/t17/README.md)。

- 一轮真实 MiMo 的无界面进程死亡恢复未能在 120 秒内持久化完成，尽管外部文件已写完；后续三轮独立通过尚未定位该间歇问题。
- Galaxy S23 的最终首次配置和完整组合尚未完成；Xiaomi 15、物理平板及厂商后台行为仍有未测项。
- 固定 x86_64 Termux 在 16 KB 页模拟器上的 bootstrap 限制仍保留；4 KB 模拟器通过不代表该问题已修复。

CI 检查主机 Runtime/UI/Python 测试、Android 编译与 lint。发布流程验证签名、版本和非调试属性，并在独立 Android 16 模拟器上启动同一签名 APK；这些自动检查不代替真实 LLM、原文件与目标手机的完整验收。历史实际验证记录随源码保留，发布包不包含模型密钥。

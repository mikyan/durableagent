# 一个共享 SDK 存储域承载产品会话

2026-11-03，用户通过 Q13、Q14 确认：每个产品会话关联一个 SDK conversation，全部产品会话共用同一个 SDK Storage，同一时刻由一个活动 SDK Session 拥有其写入，而不是按会话或项目拆分 SDK 存储域，以简化历史恢复、跨会话路由与共享数据协调。
代价是迁移与数据故障的影响面更集中，产品会话与 SDK conversation 的生命周期关联也更紧；共享存储不混合会话上下文，不要求不同会话串行执行，也不要求 Session 内存实例永不重建。
该决定不选择数据库引擎、物理文件数量或应用元数据位置，不将原生紧急控制、凭据和外部执行记录并入同一事务，也不授权开始实现；详细取舍见[数据设计](../data-design.md)。

# TypeScript 承接业务协调，Kotlin 保留 Android 控制

2026-11-03，用户确认由本应用运行宿主内的 TypeScript 核心承接会话与工作区协调、应用策略、Pi SDK 接入和领域记录的组织，而非由 Kotlin 主协调、TypeScript 只做薄 SDK 接线，以集中业务知识、复用 SDK 并便于测试。
Kotlin 负责 Android 生命周期、系统授权与其他平台事实、原生能力及 JS 无响应时的紧急控制，不复制 Pi Durable 的执行／恢复状态机，也不把终止引擎等同于外部命令全部停止。
该分工保留跨语言协作成本，不锁定数据库、控制记录或通信协议，也不表示运行时已通过验证或已授权开工。

## 用户特别明确的区分

- **系统授权**由 Android 管理，首版照常申请、检查并处理拒绝或撤销；Termux 自身外部调用配置另属初始化条件。
- **操作审批**是应用逐操作向用户请求批准，首版 YOLO 不实现该流程、审批队列或审批弹层。
- 省流、用户停止、工作区协调、执行核验和调用者身份检查仍须生效；它们不因此变成操作审批。
- 未来操作审批保留接入位置，但不为它建设首版空框架，也不把它与系统授权合并成含混的“权限”机制。

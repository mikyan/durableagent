# 以完整 Termux 环境优先保留工具安装能力

2026-11-03，用户明确要求完整 Termux 环境，并以 Android 场景中尽可能广泛的兼容工具和依赖安装能力为目标，因此采用完整 Termux 环境作为命令行基础，不以有限预置命令或少量解释器组成的工具箱替代。
完整指保留包管理、按需安装和升级工具及依赖的环境能力，不要求将整个仓库预装进 APK，也不保证任意桌面 Linux 软件或需要 root 的能力可用；主 Agent 仍由本应用运行宿主托管，Termux 承担命令及工具执行，不接管主 Agent 会话。
本决策本身不选择内嵌或受管外部 Termux、应用包名与签名、包源集成、目标 SDK 或 Agent JavaScript 引擎，也不授权卸载或替换现有 Termux 安装；后续已通过 [ADR 0005](0005-managed-external-termux.md) 确认优先采用独立官方 Termux，其余具体兼容策略仍待决定。

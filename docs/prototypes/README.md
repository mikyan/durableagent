# 会话页面样式原型（可丢弃）

## 当前结论

2026-11-03，用户否定第一轮 A／B／C，明确选择 **Hermes Console 作为手机界面与交互基线**。不再继续发散 3 种无关设计。平板在同一视觉体系上适配横屏，Pi Pocket 桌面端仅作为大框架信息布局参考。

用户随后澄清：聊天框上方横线是上拉详情入口，而不是装饰。这里改用附件加号左侧的四宫格按钮；附件菜单缩小为就地弹出的相机／图库／文件菜单。长截图用于展示详情面板的全部内容，不代表面板一次占用的屏幕高度。

**2026-11-03，用户确认：“没问题，这原型没问题了”。** 确认对象是 `conversation-ui.prototype.html`，对应已发布原型 `android-agent-ui-prototype` 的第 2 版。该版作为后续手机和平板界面实现的布局与交互基线，第一轮 A／B／C 不再作为候选方向。

确认结果已写入 `docs/requirements-v1.md` 第 2.2 节。原型解决的是页面设计问题，不代表真实功能或 Android 能力已经验收；不据此锁定 UI 框架、运行时或执行后端。原型控制条、模拟数据和预览尺寸不属于正式产品要求。正式实现须重新编写，没有据此新增 ADR。

## 启动

在项目根目录运行：

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory docs/prototypes
```

- 聊天：<http://127.0.0.1:4173/conversation-ui.prototype.html?variant=console&screen=chat&preview=auto>
- 首页：<http://127.0.0.1:4173/conversation-ui.prototype.html?variant=console&screen=home&preview=auto>
- 横屏平板：<http://127.0.0.1:4173/conversation-ui.prototype.html?variant=console&screen=chat&preview=tablet>

文件自包含，也可以直接打开 `conversation-ui.prototype.html`。Pi Pocket 中发布的 HTML 快照可直接使用，不需要连接这个本地服务器。

## 当前页面和布局

- 手机：独立首页、聊天、会话列表、项目、工具、模型和设置。
- 详细页共用一个顶栏组件：左侧菜单／返回、居中标题胶囊、右侧相关操作；首页有独立品牌与状态布局。
- 聊天使用平铺回复、顶部新建会话、会话内提问浮条、底部输入胶囊，以及独立的上下文／模型／YOLO 状态胶囊。
- 四宫格按钮打开会话详情：跳转、当前会话搜索、前后会话、模型、权限、上下文、工作区和执行记录等。详情面板有固定可视高度，内部滚动。
- 附件加号打开 3 行小菜单：相机、图库、文件。相机入口通过文件选择器的 capture 提示工作，实际选择器由设备决定；不调用后台摄像头。
- 横屏平板预览尺寸为 1280 × 800，左侧导航默认展开，聊天右侧展示文件变更与示例 diff；两侧可收起。900px 及以上使用宽屏工作区布局，较窄时调整侧栏与变更区宽度。
- 手机版把文件变更放在按需打开的面板中，不常驻挤占聊天区域。

底部紫色控制条是原型工具，不属于产品设计。它切换当前屏幕／手机／平板横屏预览，右侧 `···` 可跳转页面、改变模拟状态、放入示例附件、查看状态或填写反馈草稿。尺寸与页面参数写入 URL；受限沙箱不允许时，仅在内存中切换。

## 可试的交互

1. 长回复滚动时查看提问浮条；点击返回对应提问，或关闭该条浮条。
2. 通过顶栏加号直接新建默认会话。
3. 在四宫格入口中打开详情、切换前后会话、搜索当前会话、查看上下文并选择示例模型。
4. 选择图片或文件，检查附件草稿和发送后的消息布局。每个会话分别保存内存中的文字与附件草稿。
5. 在横屏平板里一边读回复，一边切换右侧文件及 diff；也可以收起侧栏或变更区。
6. 从侧栏进入首页与详细页，检查统一顶栏和导航结构。

## 边界

- 不连接模型，不执行 Bash，不扫描、改写或删除设备文件。
- 用户主动选择的图片只在当前页面内存中预览；其他附件只显示名称与大小。没有上传、服务端保存或浏览器持久化。
- 会话、项目、消息、开关和附件草稿刷新后重置。URL 只保存预览尺寸与页面，不保存用户输入。
- 文件变更、token 用量、模型列表、网络和恢复状态都是示例，不是 Android 能力验证。
- API Key 输入被禁用；语音入口仅保留位置，没有录音、识别或通话实现。
- 没有复制截图中的 Cron、独立任务中心、宠物、长期记忆或多 Agent 管理。详情面板只放当前范围内的入口。
- 无生产构建、前端框架选择或测试套件。`data-build="production"` 仅隐藏原型工具，不会把这个文件变成正式实现。

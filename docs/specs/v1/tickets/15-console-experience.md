# T15：完成 Console 基线的手机与横屏平板体验

## 已实施切片的后续事项

- T05：真实无效凭据已返回 401 并阻止模型请求，但界面仍显示原始英文错误 JSON。本票提供可操作的中文提示与模型设置入口，保留失败类别。
- T06：同一验证会话域内，实际 SIGKILL 界面后两份已保存草稿均完整恢复，但初始选中页可能回到较早会话。核对最后选中会话的恢复体验；页面偏好不作为草稿内容的持久化权威。[原始失败与完整草稿读回证据](../../../evidence/t06/README.md)已保留，具体偏好恢复原因尚未证实。

## What to build

将已贯通的会话、输入、模型、工作区、工具状态和文件变更组织成用户已确认的 Console v2 页面。手机保留简洁聊天与侧栏导航；横屏平板默认展开侧栏，并可在对话右侧查看文件变更。正式实现采用 React 组件及真实应用数据。

## Acceptance criteria

- [ ] 详情面板可搜索当前会话记录、定位对应消息并切换前后会话；分页历史的查询范围和未加载状态明确，跳转保持正确会话与位置，不扩展为全局搜索。
- [ ] 独立首页、聊天、会话列表、项目、工具、模型与设置可导航；详细页采用一致顶栏几何布局、标题与操作区，首页保留独立布局。
- [ ] 聊天右上角加号直接创建默认会话；新建不强制选择项目。侧栏切换会话后显示各自历史、输入草稿与执行状态，不串写。
- [ ] 输入区同时清晰展示上下文占用、当前模型和 YOLO；YOLO 明确指操作审批模式，系统授权缺失另行显示。不能展示固定示例数字冒充真实统计。
- [ ] 上下文统计由实际模型上下文／用量投影提供，区分估算与已知值；无法获得时显示不可用或估算状态，不将累计用量直接冒充当前上下文占用。
- [ ] 附件加号左侧独立详情／配置按钮在手机与平板采用相同打开方式；无输入框上方上拉横线。详情面板限制可视高度、内部滚动，并能查看当前会话模型、工作区、上下文和执行信息。
- [ ] 附件入口以贴近输入框的小菜单提供图片／文件选择及可用的相机入口；取消选择保持原草稿。必要 Android 授权由系统处理，不新增应用逐文件审批。
- [ ] 对应用户输入离开可视区域时显示会话内浮条；点击可定位原输入，并可关闭。不创建系统悬浮窗或独立 PiP 助手。
- [ ] 平板横屏默认展开左侧导航，可展开／收起右侧文件变更；手机通过按需面板查看同一数据。窗口变窄、旋转、键盘出现及较大字体时仍能发送、停止和关闭面板，正文与控件不被遮挡。
- [ ] 文件变更来自已确认的受管文件操作，展示对应原件／副本语义和可得的 diff；无法完整确定变化时明确标识。不得显示原型示例 diff 冒充真实变更，也不承诺扫描任意外部命令的所有文件变化。
- [ ] 草稿保存中／失败、发送意图未确认、SDK 已接纳、执行等待原因、停止处理中／未确认和最终失败均有可识别展示；重连不将暂时断开改写成完成或再次发送。
- [ ] UI 扩展可以使用既有详情／辅助区域并保留宿主导航一致性；页面卸载只结束 UI 资源，不影响正在执行的会话。
- [ ] 对照已批准原型完成手机与横屏平板视觉及交互验收；正式界面没有原型控制条、模拟状态切换、固定示例数据或可点击但未实现的功能假象。

- T06：文字草稿与附件输入。
- T08：项目／工作区位置绑定。

## Implementation notes

**已确认约束：**沿用 Console v2 布局与交互，TypeScript + React + Vite 的构建产物随 APK 打包；不把一次性 HTML 原型直接当产品工程，不在 APK 运行 Vite 开发服务。

**本轮自主细化：**各功能票已提供可演示的最小 UI，本票负责跨页面的一致体验和响应式收尾。以内容可用宽度选择布局，不把原型的固定预览尺寸当设备白名单；消息、草稿、状态使用稳定会话标识，页面本地只持有展示状态。普通 UI 状态可重建，耐久事实仍由原生记录、核心与 SDK 对应所有者提供。

上下文显示采用当前会话实际解析后的模型上限与可获得的上下文统计；统计缺失或估算时显式降级。文件变更区域消费 T10 的受管变更事实，记录不足时显示范围／未知原因，不为 UI 补齐而偷偷新增完整文件树、终端或产物导出系统。

**仍需验证：**真实 WebView、输入法、无障碍字体和目标平板上的布局。原型允许的示例交互只作为需求内的交互证据，不自动增加语音、全局搜索或历史物理删除能力。

## Test seam

从用户可见交互检查导航、打开详情、选择附件、切换会话、滚动浮条、侧栏和变更面板。受控应用 Interface 复现保存失败、失联及停止未确认等状态；端到端关键路径再连接真实已实现能力。进行手机窄屏、横屏平板、键盘及大字体截图／交互检查，不以 DOM 结构快照代替可用性。当前原型没有生产测试套件，不声称已有 UI 回归测试通过。

## Scope and execution boundary

不加入 Cron、独立任务中心、宠物、长期记忆、多 Agent 管理、语音识别／通话、完整文件浏览器或专门产物导出。产品中的逐操作审批仍不在首版。本次只发布工单，正式 UI 实现和设备验收待后续执行授权。

# T17：在目标设备验收真实文件工作、恢复与停止闭环

## What to build

形成首版可发布与否的完整证据：在目标手机上新建无项目会话，处理一批实际存在且获授权的文件；中途断网、回收进程并恢复，确认已完成操作不无故重复，未知副作用先核验，主动停止后不会复活。同时覆盖手机与平板体验、权限、首次初始化和数据故障的首版承诺。

## Acceptance criteria

- [ ] 小米 15 与 Galaxy S23 分别记录实际 Android／ROM 版本、ABI、页面大小、应用版本、签名标识、SDK 锁定版本和 Termux 版本／渠道；用户报告的 Android 16 不替代现场核验。
- [ ] 每台手机从首次初始化开始走完真实路径；必要命令由应用完整提供并可复制，应用检查实际就绪。完成后普通冷启动、执行桥死亡和进程回收不依赖用户再次手工打开终端或输入启动命令。
- [ ] 在经授权的测试数据中，以无项目会话操作原文件完成批量工作；操作前后内容、输入身份、受管执行身份和结果可对照，证明不是只修改上传副本。
- [ ] 在发送意图持久化、SDK 接纳、模型响应、外部效果发生以及效果收据保存的关键窗口注入中断；恢复后同一次发送不新增第二次接纳，已知完成效果不重复，未知效果未核验前不盲目重放。
- [ ] 分别覆盖断网恢复、UI 重建、运行进程终止、Termux 执行端终止、整机重启首次解锁；满足条件后无需再次发送“继续”。模型有界重试的等待原因、次数或下一步可见。
- [ ] 分别强行停止本应用和 Termux，并验证系统阻塞被如实展示、不会绕过系统限制；所需用户重开步骤不得与普通冷启动混为一谈。
- [ ] 在模型请求、工作区排队、命令运行以及 JS 无响应时停止；随后恢复网络、重建宿主并投递旧回调，旧工作不会复活。外部命令停止未确认时保持未确认，不用进程消失冒充成功。
- [ ] 同目录不同工作区记录的潜在写入保守串行；读取／状态查询仍可进行。已开始工作的绑定保持稳定，系统授权撤销或来源失效时明确受阻，不改用新位置或旧缓存冒充成功。
- [ ] 受限网络中模型请求和受控纯本地操作按政策继续，非模型／不明网络行为等待或临时放行；运行中网络切换同样生效，测量并说明策略边界，不宣称系统级零流量防火墙。
- [ ] 核验已保存草稿不自动发送、附件输入版本稳定、凭据锁屏可用性、空间不足及保存失败、迁移失败原数据保留，以及云／设备迁移排除。设备或通道未测就标未测，不能用一个 manifest 开关代替证据。
- [ ] 手机完成 Console 主路径和完成通知，通知不可用时界面仍可查看结果；平板横屏布局与功能完成验收。计划平板的准确型号／系统未确定时，记录实际已测平板或模拟环境并保留硬件待验项，不宣称已通过指定平板实测。
- [ ] 发布验收报告逐场景列出版本、前置条件、操作、观察结果、产物／日志引用、通过／失败／未测及复现步骤；任何自动续跑、普通启动或主动停止硬门槛失败均阻止宣称首版通过，并指向需要修复或复审的路线。

- T13：省流模式。

- T15：手机／平板 Console 体验。

## Implementation notes

**已确认约束：**首版按 Android 16 起、ARM64 设计；先用现有两部手机，平板布局与功能不能因硬件信息未确定被取消。完整 Termux 环境、初始化后免重复手工启动、真实原文件工作、自动续跑和停止不复活均是硬门槛。

**本轮自主细化：**采用可重复的小型测试数据集和显式故障注入点，先记录效果再比对恢复结果；每个场景绑定具体构建与环境，保留脱敏证据。故障注入区分应用进程退出、Termux 进程退出、系统 force-stop 和重启，不以一种模拟替代其他系统路径。发布检查读取前置票的契约结果，最终闭环只补平台和多能力组合的证据，不重建另一套业务测试。

**退出条件：**若本应用运行时、官方 Termux 受管启动或目标 ROM 生命周期无法满足已定体验，记录最小复现及候选差异，停止宣称交付并请求路线复审；不得静默降低 target、把主 Agent 移到外部 Termux、改成日常手工启动或取消平板要求。

## Test seam

最高入口是用户可见会话动作及应用 Interface，最终以真实文件效果、耐久重开结果、系统启动／停止结果验证。T01/T02/T03 的兼容与存储门槛、各功能票的故障用例是输入；本项目目前尚无执行结果。已有研究与原型均不得作为本票通过证据。

## Scope and execution boundary

这是验收工单，不授权本轮立即安装、连接设备、读取用户原文件、使用真实 API Key、替换／卸载／清空 Termux 或进行迁移。后续执行前须取得具体设备与测试数据范围的授权；`ready-for-agent` 仅表示工单已可领取设计工作。首版不承诺进程永不退出、固定唤醒时间、模型零重复计费、旧 Android／32 位支持或所有厂商迁移软件均受控制。

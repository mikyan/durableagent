# Domain documents

本仓库使用单一领域语境。设计、写票或实现前读根目录 [GLOSSARY.md](../../GLOSSARY.md)，使用其中的会话、项目、工作区、草稿、发送意图、系统授权与操作审批等词汇。

涉及架构选择时读 [ADR](../adr/) 中相关记录。根需求与接受状态见 [requirements-v1.md](../requirements-v1.md)、[technical-design.md](../technical-design.md)；首版收敛契约见 [spec](../specs/v1/spec.md)。不要把候选验证顺位写成生产选型。

新增术语仅在含义确实改变时更新 glossary；重大、难逆转且有替代方案的决定才写 ADR。普通字段、接线与测试细化放在对应 spec 或工单。
